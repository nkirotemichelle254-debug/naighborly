# Naighborly Prototype

This is now a navigable static prototype instead of a single showcase screen.

## Pages

- `index.html` - login
- `home.html` - feed
- `details.html` - single post view
- `inbox.html` - conversations and thread
- `create.html` - create-post wizard
- `profile.html` - user profile

## What works

- Real page-to-page navigation
- Clickable post cards leading to details
- Login form redirect into the app
- Bottom tab navigation between major screens
- A working three-step create-post flow

## Open it

Start with `index.html` in a browser.
